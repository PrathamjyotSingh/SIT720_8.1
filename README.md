# SIT720 8.1 – Sydney Housing Price Prediction

Machine learning mini project for **SIT720 Machine Learning – 8.1 Distinction Task**.

The project develops a Sydney housing price prediction and decision support system, including data analysis, feature engineering, regression modelling, evaluation, and a web-based prediction application.

## Files

* **Notebook** – Data preprocessing, analysis, feature engineering, model training and evaluation.
* **CSV** – Sydney housing dataset used for the project.
* **App** – Web application for housing price prediction.
* **Model** – Trained machine learning model used by the application.
* **Requirements** – Python libraries required to run the project.

## Run the Application

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
